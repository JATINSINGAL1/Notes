```
enum example{
A, B , C 
};
``` 

Enum are nothing just bunch of integers grouped together. 
by default values defined to these integer start from 0 and get increment by 1. 

We can also initialize our own values we want. 

if we initialize A = 3 by default B would be = 4 ;

we could use this datatype to set certain restriction to integer value we want for e.g.
`example var = 5` will show an error as the according to our datatype var can only be A, B ,C ;

**We are using name of var as Integer value**
